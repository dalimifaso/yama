# ימאות

חוברת תרגול אינטראקטיבית למבחן משיט — עמוד HTML אחד, בלי תלויות ובלי שרת.

**להריץ:** לפתוח את `index.html` בדפדפן. הכול מוטמע בקובץ, כולל התמונות, כך שהוא עובד גם בלי חיבור לרשת (פונטים בלבד נטענים מ-Google Fonts, ובלעדיהם נופלים לפונט מערכת).

## מה יש בפנים

| עמוד | תוכן |
|---|---|
| **כלי השייט** | ציור מפרשית עם 27 חלקים ממוספרים, סימולטור זווית רוח, פאנל CE/CLR, 67 שאלות וסיכום חומר |
| **אורות וסימנים** | 133 סימנים: זיהוי אורות, סימני יום, דגלים, אותות קוליים וסימני מצוקה — עם משוב מיידי, טריק זכירה לכל סימן, והשמעת האותות הקוליים |
| **מטאורולוגיה** | 40 שאלות, סיכום חומר ומחשבון בופור |
| **חוקי דרך** | משחק "מי מפנה?", 22 שאלות וסיכום חומר |
| **מקרים ותגובות** | 42 תרחישים וסיכום חומר |

סה"כ 304 פריטי תרגול.

## מבנה

```
template.html     המבנה, העיצוב וכל הקוד. מכיל סמן /*__DATA__*/ אחד
blobs/*.json      התוכן — שאלות, תשובות, טריקים, סיכומים, חלקי הספינה ותמונות מוטמעות
build.py          מזריק את blobs/ לתוך template.html
index.html        הפלט: מסמך עצמאי (נוצר אוטומטית — לא לערוך ידנית)
dist/artifact.html גוף העמוד בלבד, לפרסום כ-Artifact
serve.py          שרת פיתוח מקומי עם UTF-8 תקין
```

## בנייה

```bash
python3 build.py
```

ספרייה סטנדרטית בלבד, בלי התקנות.

לעריכת תוכן — משנים את קובץ ה-JSON המתאים ב-`blobs/` ומריצים מחדש את `build.py`.
לעריכת עיצוב או התנהגות — משנים את `template.html` ומריצים מחדש.

### מבנה הנתונים

- `DATA.json` — הסימנים: `{n, cat, a, tip, img, lab, pat?}`. `img` הוא data URI, `pat` הוא תבנית האות הקולי
- `MET / RULES / CASES / BOAT.json` — שאלות: `[שאלה, תשובה נכונה, [3 מסיחים], טריק]`
- `NOTES.json` — סיכומי החומר: `{עמוד: [[שם נושא, [[מונח, משמעות], ...]], ...]}`
- `PARTS.json` — חלקי הספינה: `[מזהה, שם, x, y, הסבר]` בקואורדינטות ה-SVG
- `DUEL.json` — סדר הפינוי בין קטגוריות כלי שייט

## מקורות

התוכן מבוסס על חוברת העזר למבחני משיט של משרד התחבורה — מינהל הספנות והנמלים, המחלקה לכלי שיט קטנים — ועל סיכומי הקורס של דרך הים. קובצי המקור עצמם אינם נכללים במאגר.
